# Database Project

University project focused on the design and implementation of a relational database, including database modelling, SQL queries, and the development of a Java prototype application interacting with the database.

## Project Overview

The project covers the main stages of database development, from the conceptual and logical design of the database to its implementation and integration with an application prototype.

The repository contains:

* A **PDF document** describing the database design and the implemented SQL queries.
* **Java source code** for a prototype application that interacts with the database.
* A **video demonstration** showing the functionality of the application prototype.

## Technologies

* **Java**
* **SQL**
* **Relational Database**

## Purpose

This project was developed as part of a university course on databases, with the goal of gaining practical experience.
